# Vibe Service Guardian 0.8.5.2 上线准备度审查

审查日期：2026-08-17
范围：0.8.5.2 P1 功能、Windows 本机验收及一次受限的 macOS x86_64 VMware 预览验收；不含 Release、代码签名、公证、自动更新或完整跨平台真机矩阵。

状态注记（2026-08-17）：本审查的验证结论形成于功能分支阶段；功能随后通过 PR #5 合并到 `main`（`60794a1`）。合并改变了源码分发状态，但没有补充目标平台真机证据，也没有把本结论升级为稳定版或完整跨平台支持声明。在本次 Alpha 元数据审查时，标签和 GitHub Release 尚未创建。

## 结论

**当前结论：适合作为本机单用户 Alpha 的 Windows 未签名便携候选；macOS x86_64 只能声明为受限 VM 预览，不应声明为跨平台生产就绪。**

本版本解决日常入口和决策闭环，但没有扩大停止权限。项目级计划仍逐服务确认，提醒只在本地持久化，桌面集成默认关闭且不提权。剩余阻断项主要是目标平台真机证据、未签名分发信誉和真实用户长期样本，而不是缺少自动控制能力。

## 当前主机验证

- 当前 Windows 源码树共 243 项 unittest：242 项通过，1 项为 Windows 不适用的 POSIX 权限位断言跳过；P1 专项 10 项和 macOS 验收脚本专项 9 项均通过。
- Ruff、前端 JavaScript 语法、20 份依赖哈希锁、公开目录审计、Bandit 中/高风险门禁、`pip check` 与差异格式检查通过。
- Windows 未签名 EXE 原生回环 smoke、托盘启停、中文/英文 Edge 交互、归档契约与 checksum 验证通过；最终散列以归档旁 `.sha256` 为准。
- macOS 13.7.8 x86_64 AMD/VMware 客体上的 r8 构建通过 `MACOS_NATIVE_VALIDATION_OK`；测试套件整体为 OK，其中 1 项 Windows Git Bash 专用测试按平台跳过，Mach-O 与 ad-hoc 签名检查通过。该结果只证明受限 VM 自动验收；人工清单未勾选且没有界面截图，r8 证据 ZIP 还存在最终日志封装过早的问题，因此不能作为完整人工验收。
- r9 已在 Windows Git Bash 的自包含回归中覆盖启动复用、正常清理、VSG 退出证明、最终状态持久化、完整日志封装和 AppleDouble 排除；r9 尚待同一 macOS 目标环境复验。
- 验证没有停止用户服务、运行真实模型负载、写入开机启动项、注册全局快捷键、推送代码或发布 Release。

## 仍然阻断公开稳定发布

1. Windows 10、Apple Silicon、实体 Intel Mac、Ubuntu x86_64/aarch64 的真实机器验收仍未形成完整矩阵；现有 macOS x86_64 VMware 结果只能计为预览证据。
2. macOS/Linux 没有托盘实现，本版本只能声明跨平台 Web 控制台继续可用。
3. Windows 包未签名；SmartScreen/信誉提示、证书托管与发布人身份链尚未解决。
4. 项目清理和提醒中心缺少多周真实用户样本，当前只能证明逻辑、迁移、回环 API 与本机 UI 路径。
5. systemd/launchd 原生 unit/label 证据与真实 Hermes/OpenCode 版本矩阵仍属于 0.8.6 P2-B。

## 发布边界

- 原验证轮次没有推送或发布；功能后续已合并到 `main`。任何 Alpha Release 仍须基于最终 `main` 重新构建、重新验证归档并生成新的 SHA-256。
- 只有当前主机完整测试、静态/安全门禁、Windows 便携构建、原生 smoke、归档与 checksum 全部通过，才可称“当前 Windows 主机候选验收通过”。
- macOS x86_64 保持“源码与构建链适配、VM 自动验收预览通过、r9 与实体机待验收”；Apple Silicon 与 Linux 保持“源码与构建链适配、目标平台待真机验收”。

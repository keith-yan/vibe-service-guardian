# Vibe Service Guardian 0.8.5 上线准备度审查

审查日期：2026-08-15
范围：0.8.5 P2-A 本地功能分支；不含提交、推送、Release、系统托盘、systemd/launchd 深度采集或跨平台真机发布。

## 结论

**当前结论：可继续作为本机单用户 Alpha 和代码评审候选，不应声明为跨平台生产就绪。**

0.8.5 P2-A 把归属纠正从“覆盖当前快照”升级为确定性规则资产，并补上版本、回滚、冲突、命中、被覆盖和 episode 纠正率证据。规则包采用显式导出、完整性预览和逐条重绑定；Agent 子进程保持停止保护；Docker 不再读取完整 inspect 对象。这些变化降低重复误判和容器元数据过度读取风险，但没有改变单用户、回环、本地控制面的产品边界。

## 仍然阻断公开稳定发布

1. Windows 10、Apple Silicon/Intel macOS、Ubuntu x86_64/aarch64 真实机器验收仍未完成；当前 Windows 主机不能替代这些证据。
2. systemd/launchd 的 unit/label 归属仍以可见父链和只读建议为主，尚未完成 0.8.6 P2-B 的原生证据矩阵。
3. 规则导入导出需要更多真实多机样本验证冲突可理解性；当前实现刻意要求逐条重绑定，不能宣传为自动同步。
4. 未签名便携包仍会触发平台信誉提示；没有证书、公证或自动更新链。

## 发布边界

- 本轮只在本地功能分支修改，不提交、不推送、不发布。
- 只有完整自动化、本机 Windows 便携构建与 smoke 均通过后，才可称“当前 Windows 主机本地验收通过”。
- macOS/Linux 保持“代码与构建链适配、真实平台待验收”；路线图已顺延至 0.8.6 P2-B。
